# Lcs

Topic: **dp** / `lcs`

Longest common subsequence length between two strings.

**Complexity:** length: Time O(nm); Space O(min(n,m)).

**Worked example:** [Topic index](../../worked-examples.md#lcs) (summary) · run `npm run demo -- lcs` in all three languages.
