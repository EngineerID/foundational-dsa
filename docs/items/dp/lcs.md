# Lcs

Topic: **dp** / `lcs`

## Overview

Longest common subsequence length between two strings.

**Walkthrough:** [Worked examples — Lcs](../../worked-examples.md#longest-common-subsequence).

## Complexity

length: Time O(nm); Space O(min(n,m)).

| | Time | Space |
|---|------|-------|
| Primary | Time O(nm) | Space O(min(n,m) |
